# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
|---|---|
| 2.1.x | да |
| 2.0.x | только критические исправления |
| < 2.0 | нет |

## Как сообщить об уязвимости

**Не открывайте публичный issue** для уязвимостей и случаев утечки данных.

Используйте приватный канал GitHub: вкладка **Security** → **Report a vulnerability** (GitHub Private Vulnerability Reporting). Если канал недоступен, свяжитесь с сопровождающим проекта через профиль [@DenisZakharov2](https://github.com/DenisZakharov2).

В сообщении укажите:

- затронутый файл или артефакт;
- шаги воспроизведения;
- потенциальное влияние;
- предлагаемое исправление, если известно.

## Что считается уязвимостью

- персональные данные, пароли, API-ключи или токены в примерах, артефактах и журналах `*_flight_log.json`;
- выполнение недоверенного кода при рендере Mermaid, Marp, PPTX или Typst;
- подмена артефактов между агентами в обход `hermes-orchestrator`;
- обход Stage-Gate, Triple-Gate или лимитов Self-Healing.

## Область действия

Репозиторий содержит документацию, скиллы и JSON-схемы. Уязвимости инфраструктуры Hermes Agent и сторонних библиотек следует сообщать их сопровождающим.
